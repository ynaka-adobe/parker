# cards-teaser

Custom **cards** block. Purpose: teaser tiles linking to sub-pages (e.g. Aerospace Submarkets).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: [picture] | [H3 title, short description paragraph, 'Learn More' link].
