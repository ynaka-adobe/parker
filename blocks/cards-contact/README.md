# cards-contact

Custom **cards** block. Purpose: contact directory (e.g. HR & Benefits).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per contact group, 3 cells: [H3 group heading] | [phone (tel: link), may be empty] | [details: address lines, links, email].
