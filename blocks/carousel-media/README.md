# carousel-media

Custom **carousel** block. Purpose: image + text feature slides (product updates, app FAQ).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per slide, 2 cells: [picture] | [eyebrow p, H2, paragraph(s) or ul, optional CTA link].
