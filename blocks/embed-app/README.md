# embed-app

Custom **embed** block. Purpose: full-width interactive app iframe.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Class | Description |
|---|---|---|
| Launch panel only | `launch` | Always shows the launch panel (button opens the app in a new tab), even on allow-listed hosts. Use for apps that can't be framed anywhere, e.g. the Help & Support Master Directory. |

The cell's link text is the app name used in the panel heading and the "Launch …" button; a bare URL falls back to "Parker World".
